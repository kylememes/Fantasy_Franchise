# Coach specialties and player cards

All 32 head coaches have original game-assigned specialties. These are gameplay choices, not official evaluations, licensed coach ratings, or guarantees about real people. Each coach offers one +2 specialty and one +1 specialty. A pass-rush specialty applies to both power and finesse moves so either rushing style benefits. Coordinators remain cosmetic.

Human owners hire available coaches directly. CPU franchises leave head-coach positions vacant through Preseason Week 1, then fill vacancies from the remaining coaches in the commissioner's Week 2 advancement transaction, before CPU game inputs freeze. CPU preferences consider saved scheme identity with deterministic tie-breaking. Existing human hires and completed game results are preserved. Owners may replace staff; changes affect future kickoffs, never a queued or saved game.

The database computes effective game attributes from the source profile, exact position eligibility, existing attribute aliases and an overall fallback for unavailable attributes. Each attribute caps at 99. The roster's original ratings and overall do not change. Player card previews use the same definitions and are tested against database output for every coach. Badges and card backs show actual applied deltas, including a smaller increase when capped. Cards prioritize position-relevant attributes and statistics. Missing blocking or kicking statistics are shown as unavailable rather than invented.

New frozen inputs carry coach_bonus_version 1 and use football engine V2. Inputs frozen before this update keep V1 behavior; a deterministic regression test verifies an existing input's exact result hash. The worker's commit function validates engine version against frozen inputs.

## Star player headshots

All 604 current real players tagged Star, Superstar or Franchise Superstar are matched across positions: 493 Stars plus the previous 111 Superstars and Franchise Superstars. ESPN provides 469 photos; official NFL roster headshot URLs cover the remaining 135 players. Matching uses exact nflverse GSIS ID and roster name, with six documented supplemental ESPN roster matches verified by name and birth date. The Wayne Matthews II/III source-name discrepancy is additionally corroborated by Michigan State college and Chicago team. Card eligibility is checked on every render: eligible development tiers only, never fictional players. Normal and unrevealed tiers, missing identities and failed image loads use the existing silhouette. Photo lookup uses a shared identity index.

Images are displayed from ESPN's public headshot CDN or the official NFL image CDN, loaded lazily without sending the league URL as a referrer. No image files are copied into this repository. data/player-headshots.json records identities, photo providers, public image URLs and the roster metadata source. Every URL was checked for a successful image response on the recorded verification date. This records provenance and technical availability; it does not claim that nflverse's data license grants rights to third-party photographs. The source can be disabled or replaced independently of player identity and ratings.

Validation includes position filtering, capped boosts, no base-profile mutation, exact identity matching, photo error fallback, shared hiring conflicts, human-first timing, CPU hire uniqueness/idempotence, frozen input stability, and legacy simulation compatibility.

## Coaching workspace

The Coaching tab includes three staff cards, offensive and defensive playbook descriptions, roster-fit estimates, grouped preferences, and completed-game results. Current staff hires have no salary-cap charge or fixed expiration in the game; the UI labels terms open-ended and salary/years as not tracked rather than inventing contract numbers.

Playbook fit is a transparent roster-rating heuristic: each scheme specifies position groups, required depth, and relevant attributes; the best eligible players fill each group, missing slots score zero, and absent attribute values fall back to overall. Group averages are weighted equally. This estimate is not a simulation forecast or a guarantee. Simple tendency choices map to 25/50/75 in the existing saved controls; custom values remain visible and editable in advanced sliders. Save failures preserve edits, and concurrent versions require reloading before overwriting.

Results read only the user's team's finalized games from the existing membership-guarded season/game snapshot RPCs. Preseason and regular season are separate. Yards, sacks allowed, third downs, and attempts come from final box scores. Passing yardage is net of sacks, consistent with the engine. Run/pass share excludes sacks and uses recorded attempts. Fumble recoveries equal opponent fumbles lost; interceptions come from defensive player totals. Coverage and blitz percentages exclude special teams, spikes, and kneels. Blitz denominators include only plays with an explicit recorded flag; old games without this data show unavailable rather than zero.

Red-zone possessions require a snap at or inside the opponent's 20. A long touchdown from outside is not a trip. Possession changes, fourth-down failures, scores, kicks, halftime, overtime, and game end close a drive. Offensive efficiency is touchdowns / trips; defensive stop rate is trips without a TD / trips, including field goals as stops. Failed or incomplete game fetches show an error instead of partial season totals. Reports refresh on opening the tab, changing phase, or selecting Refresh results.

The six approved tab illustrations are displayed as CSS windows into `public/tab-artwork.webp`, a compressed encoding of the approved sheet. The coaching playboard has no headset; Draft uses the revised draft tickets. Scouting retains its existing icon.
